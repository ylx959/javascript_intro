# JavaScript Intro

A practice repo for learning JavaScript fundamentals, from variables all the way to classes and inheritance.

## Structure

```
.
├── index.html      # Practice web page (currently a centered button)
├── style.css       # Page styles
├── index.js        # Current practice code (class inheritance and super)
├── dice_image/     # Dice images (faces 1–6) for the dice-rolling exercises
└── tutorial_js/    # Numbered exercise files, one topic each
```

## Topics (tutorial_js)

| No. | Topics |
| --- | --- |
| 1–5 | Variables, arithmetic operators, user input, type conversion, const |
| 6–8 | Counter program, Math object, random dice |
| 9–17 | If statements, checked property, switch, string methods and slicing, method chaining, logical operators, strict equality, loops |
| 18–19 | Mini projects: number guessing game, temperature conversion |
| 20–24 | Arrays, spread operator, rest parameters, dice roller, password generator |
| 25–29 | map, filter, reduce, function declarations vs. expressions, arrow functions |
| 30–36 | Objects, this, constructors, classes, static, inheritance, super |

## How to run

1. Open `index.html` in a browser (or use the VS Code Live Server extension).
2. Open DevTools (F12) and check the Console for `console.log` output.
3. To run a specific exercise, change `<script src="index.js">` in `index.html` to that file, e.g. `tutorial_js/17_loops.js`.
